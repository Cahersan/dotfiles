# Dotfiles

Personal configuration and brief documentation for my daily tools.

## Motivation

- **Reproducible setup** on a fresh install or a new machine. Just clone and create symlinks.
- **One source of truth**, as configs live in this repo and are symlinked.
- **Changes history**, as every change to a configuration is a commit.
- **Documentation** of stuff I don't want to forget in my daily coding.


## Contents

- [Zed](https://zed.dev) editor, configured for Vim mode on Linux.
- [tmux](https://github.com/tmux/tmux) terminal multiplexer, with mouse support, Vim-style keys and sessions that survive reboots.
- [Alacritty](https://alacritty.org) terminal, styled like Zed with brighter, high-contrast colors.
